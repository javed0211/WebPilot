Implementation Plan

6 phases — Foundation through Show & Tell, all complete by 30 July 2026

Target dates

  • Project start: 8 July 2026
  • All phases complete: 30 July 2026
  • Show & Tell: 30 July 2026 — live BrowserAgent demo to stakeholders

Phase 1 — Foundation (8–11 July)

  • Install Node.js, Python 3.12+, virtualenv, and @qubiqlabs/webpilot on all machines
  • Configure qa.json, .env credentials, and Azure LLM (llm.json)
  • Validate environments and browser-use stack end-to-end

Phase 2 — Browser Agent, Data & Dry Run (11–16 July)

  • Browser Agent creation — configure Bupa BrowserAgent for target apps
  • Basic data management — knowledge store, credentials, runtime artifacts
  • Scenario identification — catalogue priority NL test scenarios
  • Dry run — smoke discovery, knowledge replay, first automated pass

Phase 3 — CRM & Clinics Digital (16–23 July)

  • CRM (Dynamics) scenarios — login, navigation, full flows with HTML reports
  • Clinics (Digital) scenarios — identify, automate, and report
  • Complete automation with execution reports for both streams

Phase 4 — Repo Integration (22–26 July)

  • Codegen — generate Playwright tests and POMs into the repo
  • Wire GitHub Actions / Azure Pipelines for webpilot run
  • Publish reports and artifacts from pipeline runs

Phase 5 — Results & Token Dashboard (26–29 July)

  • Dashboard for test results — pass/fail, trends, execution history
  • Token usage dashboard — LLM calls, cost, and usage metrics

Phase 6 — Show & Tell (30 July)

  • 29 July: Dry run — full demo across all phases
  • 30 July: Show & Tell presentation and project sign-off
  • Demo: NL scenarios → BrowserAgent → CRM & Clinics automation → repo CI → dashboards
